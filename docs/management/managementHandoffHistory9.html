Model evaluation — summary

Read the final model evidence report (public by link, noindex; local copy .codex-work/ds-shadow/REPORT.html). It covers the r6 replay, the D697 production pilot, DeepSeek shadows, GLM-5.3 and GLM-5.3-Flash, and Astra-6 versus Astra-6.2. Its verdict: keep the cloud lead and use local models selectively.

  • r6 replay (seven retained tasks): DeepSeek passed 3/7 fixed gates and Astra-6 2/7. DeepSeek averaged 41.3 minutes per job versus 12.1 minutes, despite about 70 tokens/second local decoding. This is a small sample, not a general ranking.
  • Blind shadows (five matched tasks, randomized anonymous Opus grading): the first four-way ranking (three tasks) put the merged cloud work first, then Astra-6.2, DeepSeek and GLM. In the final six-way comparison, Astra-6.2 was about level with Astra-6: 6.2 was slightly more correct, while 6 wrote better tests, followed briefs better and was faster (23.7 versus 32.0 minutes average). DeepSeek was mid-table and won one security task outright. GLM-5.3-Flash was fast (about 59 tokens/second, 99% cache) but last; GLM-5.3 decoded at about 19 tokens/second.

Standing worker rules added this session

  • REVIEW BUDGET IS PER PR: every PR (main, sync port or follow-up) has its own review budget as stated in the brief, so a separate port PR's rounds need no grant. Extra rounds on the same PR still need a request. A delta after APPROVE that only regenerates snapshots or fixes lint or format, with no behaviour change, gets one delta-only round without asking; record it in the PR.
