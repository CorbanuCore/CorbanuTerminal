The new reading now treats braces after reserved words as group delimiters, as bash and zsh do. The new tests failed before the fix and pass after it, the 905 `security::` tests pass, and fmt is applied. `cargo clippy -p codex-core --all-targets -D warnings` is not clean, but none of the 8 errors are in files I touched.

**What changed (`codex-rs/core/src/security/tainted_action/shell.rs`)**
- `{` now opens a group in the new reading when the words before it are all unquoted reserved words that can start a command: `!`, `time`, `if`, `then`, `elif`, `else`, `while`, `until`, `do`. This covers `then {`, `do {`, `else {`, `! {`, `time {`, `! time {` and `if {`.
- `}` now closes a group when the only word before it is an unquoted `fi`, `done` or `esac`.
- A word doesn't count as reserved if it was quoted, escaped, built from a substitution, part of a redirection, or had a brace removed. So `'then' {`, `\time {`, `>then {`, `$(echo then) {` and `echo then {` still read the brace as literal and still get the second judgment. Upper-case `Then` doesn't count either.
- The group-brace check only changes in the new reading. Main's two readings (Redirections and Legacy), which set the floor, are unchanged.
- Result: the issue's spellings now read exactly as main's Redirections reading does, so the classifier no longer runs a needless second judgment on them. Brace arguments still get it, so the result is never quieter than before.

**Tests**
- `tainted_action/shell_brace_group_tests.rs` (new) covers the shell-independent lexer:
  - `issue_2018_braces_after_reserved_words_delimit_groups`: 22 spellings. It checks they aren't flagged as read differently, that the words match main's Redirections reading, and that no `{`/`}` is left as a word.
  - `issue_2018_brace_arguments_stay_literal`: 11 control lines, which pass both before and after.
- In `tainted_action_brace_reading_tests.rs`, each test runs in both bash and zsh:
  - `issue_2018_group_braces_need_no_second_judgment`: group lines skip the second judgment and control lines still get it.
  - `issue_2018_group_verdicts_never_quieter_than_main`: on 11 group lines with the existing redirected-`cd` payload (3 `cd` spellings each), the new reading alone returns `Persistence`. The full verdict is never quieter than main's Redirections or Legacy verdict.
